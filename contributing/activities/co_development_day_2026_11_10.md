# First CfRR Co-Development Day: 10 November 2026

```{card}

Sophia Nora and Juan Benavides-Tocarruncho joined Liam Berrisford for a day of learning and contributing to the CfRR courses.

**Learning through practical contributions**

The morning focused on using Git and GitHub collaboratively and working with the command line. Sophia and Juan then put those skills into practice by identifying and fixing small issues across the courses, working through the full GitHub contribution workflow from an issue to a merged pull request.

Starting with manageable tasks gave them opportunities to practise the workflow while making useful improvements to the teaching materials. The day finished with each participant developing a short course on creating packages, a topic they were both keen to learn more about.

**What we achieved**

Together, the group closed **20 issues** and merged **20 pull requests** across the CfRR repository. Contributions ranged from correcting code examples and improving quizzes to developing new teaching materials, including:

- [Creating Python packages](../../short_courses/python_packages.md), developed by Sophia Nora.
- [Building your first R package](../../short_courses/r_packages.md), developed by Juan Benavides-Tocarruncho.

Thank you to Sophia and Juan for their contributions and enthusiasm, and to Liam for hosting and guiding the session.

```
